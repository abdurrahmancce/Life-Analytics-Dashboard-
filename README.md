# life-analytics-dashboard

Production-ready, offline-first **Life Analytics Dashboard** built with pure HTML/CSS/JavaScript and Local Storage.

## Run
Open `index.html` in a browser.

## Features
- Daily activity tracking with add/edit/delete and 24-hour validation
- Date navigation and historical calendar-style analytics
- Chart.js visualizations (pie, doughnut, bar, line, area, timeline, heatmap)
- Productivity scoring, habit intelligence, goal management, insights, mood tracking, achievements
- Smart widgets, search/filters, life replay, time bank, digital addiction monitor, focus score
- Export/import JSON, CSV export, backup/restore, report generator
- Responsive glassmorphism UI with dark/light mode
